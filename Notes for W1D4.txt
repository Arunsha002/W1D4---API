API Basics
----------
API (Application Programming Interface): A backend application that acts as a bridge between the frontend (UI) and the business logic (server-side rules and data).

Types of APIs:
- REST API: Most common, resource-oriented, uses HTTP methods, responses usually in JSON.
- GraphQL: Flexible queries, lets clients specify exactly what data they need.
- SOAP: XML-based, older but still used in enterprise systems.
- RPC (Remote Procedure Call): Directly invokes functions/methods on a remote server. Modern variant: gRPC.

REST API & HTTP Methods
-----------------------
The four core methods (CRUD operations):
1. POST   → Create new data on the server
2. GET    → Read or fetch data from the server
3. PUT    → Update existing data on the server
4. DELETE → Remove data from the server

Requests and responses are usually in JSON format.

HTTP Status Codes
-----------------
- 200 series (Success): Request completed successfully (e.g., 200 OK, 201 Created).
- 300 series (Redirection): Resource moved or requires further action (e.g., 301 Moved Permanently).
- 400 series (Client Errors): Problem with the request (e.g., 400 Bad Request, 404 Not Found).
- 500 series (Server Errors): Problem on the server side (e.g., 500 Internal Server Error).

FastAPI Essentials
------------------
- Endpoints: URLs that map to functions. Example: /add → performs addition.
- Why FastAPI?
  * Very fast (built on Starlette + Pydantic).
  * Automatic validation of request data.
  * Interactive API docs at /docs (Swagger UI) and /redoc.

Setup & Examples
----------------
1. Install packages:
   pip install fastapi uvicorn

2. Hello World API (firstapi.py):
   from fastapi import FastAPI
   import uvicorn

   app = FastAPI()

   @app.get("/")
   async def root():
       return {"message": "Hello World"}

   if __name__ == "__main__":
       uvicorn.run("firstapi:app", host="127.0.0.1", port=8000, reload=True)

   Run:
   uvicorn firstapi:app --reload --host 127.0.0.1 --port 8000
   Test:
   http://127.0.0.1:8000/ → {"message": "Hello World"}

3. Calculator API (calculatorwithapi.py):
   from fastapi import FastAPI
   import uvicorn

   app = FastAPI()

   @app.get("/add")
   async def add(a: float, b: float):
       return {"result": a + b}

   @app.get("/subtract")
   async def subtract(a: float, b: float):
       return {"result": a - b}

   @app.get("/multiply")
   async def multiply(a: float, b: float):
       return {"result": a * b}

   @app.get("/divide")
   async def divide(a: float, b: float):
       if b == 0:
           return {"error": "Division by zero is not allowed"}
       return {"result": a / b}

   if __name__ == "__main__":
       uvicorn.run("calculatorwithapi:app", host="127.0.0.1", port=8001, reload=True)

   Test in browser or Postman:
   http://127.0.0.1:8001/add?a=5&b=3 → {"result": 8}
   http://127.0.0.1:8001/divide?a=9&b=3 → {"result": 3}
