Rest API and Its methods

4 important http methods for API

1. Post - Create the data to the server
2. Get - Read the data from the server
3. Put - Update the data to the server
4. Delete - To delete the data from the server


All these are the request and the response will be in a json format

200 series - success messages
300 series - redirect issues
400 series - Client side issue
500 series - server side issue
